# Реестр документации

[Реестр пилота и расширения](../examples/pilot_catalog.csv) содержит только метаданные. Локальную рабочую копию можно хранить в `data/registry/`, исходные PDF — в `data/raw/`.

- `product`, `version`, `title` — продукт, версия продукта и название руководства.
- `filename` — исходное имя файла по подписи вложения, включая расширение. При локальном импорте сопоставляйте его с физическим файлом, которому среда могла присвоить служебный префикс или изменить пробелы.
- `document_code` — шифр с титула. Вместе с продуктом и версией определяет уникальную запись.
- `scope` — `pilot` для одного пилотного PDF или `expansion` для кандидата на расширение.
- `pages` — число страниц PDF. Ссылки используют физический номер от 1.

Проверка на Python 3.13 выполняется командами `python scripts/check_registry.py examples/pilot_catalog.csv` и `python -m unittest discover -s tests/unit`. Валидатор проверяет CSV и метаданные. Сверка с содержимым PDF зафиксирована в отчётах RAG-002. Учебный CSV с четырьмя колонками по-прежнему поддерживается.
