Выбор решения для продукта требует документов о правах, согласованного состава библиотек и результатов интеграции.

### Воспроизводимые автономные пробы

- Navec 0.10.0, официальный архив hudlit v1, SHA-256 0a89ec8198d0ae9ee3bbb31bbf2c0115bf033e56a337b74d6ca1fe5623165446. Проверка после загрузки: `v = Navec.load(path)["компьютер"]`, форма (300,), все числа конечны. Тексты PDF не передавались.
- В контейнере local-ydb с указанным digest, GRPC_PORT=2136 и YDB_USE_IN_MEMORY_PDISKS=true штатный /health_check выполнил SQL и проверку схемы. Через CLI с --no-discovery запрос SELECT 1 вернул 1. Для двух ортогональных синтетических векторов (1,0) и (0,1) функция Knn::CosineDistance над Knn::ToBinaryStringFloat вернула 1. Векторный индекс, фильтры Dify и нагрузка корпуса не проверены.
