# RAG-002. Анализ пилотного PDF

Пилотный документ — «КриптоПро CSP. Инструкция по использованию. Windows», версия продукта **5.0 R4 KC1**, издание 2026 года. На титульной странице и в колонтитулах указан шифр **ЖТЯИ.00101-04 92 01**. Во внешнем имени файла указан **ЖТЯИ.00101-03 92 01**. Для будущего реестра предлагается брать идентификатор с титула, а фактическое имя PDF хранить отдельно.

## Результаты

| Проверка | Результат |
| --- | --- |
| Формат и доступ | PDF 1.5, 200 страниц, без шифрования |
| Текстовый слой | Poppler извлёк непустой текст со всех 200 страниц. В выводе режима `-layout` нет символов замены Unicode. Это проверка извлекаемости, корректность всего текста вручную не проверялась |
| Нумерация | Физические номера страниц 2–200 совпали с печатными колонтитулами. Страница 1 — титул без печатного номера |
| Таблицы | На страницах 88 и 90 визуально подтверждены таблицы № 2 и № 3. Режим `-layout` визуально сохраняет столбцы, но оставляет переносы внутри ячеек. Обычный текстовый вывод теряет связи между частью ячеек и заголовками |
| Страницы с малым объёмом текста | Страница 7 содержит короткий абзац, извлечённый полностью при визуальной сверке. На странице 162 текст внутри диалогового окна находится в изображении и отсутствует в извлечённом тексте, хотя подпись к рисунку доступна |
| OCR | Для основного текста сплошной OCR не требуется. Для вопросов по тексту внутри иллюстраций потребуется выборочная обработка изображений с проверкой результата. Русскоязычный OCR в текущей среде не проверен, у Tesseract доступны только `eng` и `osd` |

## Вывод для пилота

Документ пригоден для пилота с ответами по текстовому слою. Для ссылок используйте физический номер страницы PDF, начиная с 1. Сохраняйте продукт, версию, шифр документа, номер страницы и заголовок раздела в метаданных фрагмента. При разбиении текста учитывайте повторяющиеся колонтитулы, переносы слов и абзацы, продолжающиеся на соседней странице.

Перед включением табличных ответов приведите проверенные таблицы к структуре «заголовок столбца — строка — значение» и сверяйте знаки и многострочные ячейки с PDF. Если ответ содержится только на скриншоте и его содержимое не извлечено, бот должен сообщить о недостатке подтверждения.

## Воспроизведение

```bash
pdfinfo "$pdf"
pdftotext "$pdf" plain.txt
pdftotext -layout "$pdf" layout.txt
pdftoppm -f 88 -l 88 -png -singlefile "$pdf" page-88
```

Разделитель страниц в выводе Poppler — form feed. Для визуальной выборки использовались страницы 7, 88, 90 и 162.
