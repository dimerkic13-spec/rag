# RAG-002. Проверка руководства по виртуальным средам

Дополнительный документ — «КриптоПро CSP. Руководство администратора безопасности. Виртуальные среды», версия продукта **5.0 R4 KC1**. На титуле и в колонтитулах указан шифр **ЖТЯИ.00101-04 91 09**. Во внешнем имени файла указан **ЖТЯИ.00101-03 91 09**. Такое же различие между суффиксами 03 и 04 обнаружено в инструкции для Windows.

| Проверка | Результат |
| --- | --- |
| PDF | 17 страниц, без шифрования |
| Текст | Poppler извлёк непустой текст со всех 17 страниц. В выводе режима `-layout` отсутствуют символы замены Unicode |
| Нумерация | На страницах 2–17 физический номер PDF совпадает с напечатанным. Титул на странице 1 без печатного номера |
| Таблица | Таблица № 1 на странице 9 содержит 11 строк данных. Визуальная проверка подтвердила два столбца. В режиме `-layout` расположение столбцов читается, но переносы внутри ячеек и путей требуют восстановления |
| Блоки конфигурации | На странице 16 блоки конфигурации и команды присутствуют в текстовом слое. При подготовке фрагментов следует сохранять отступы и проверять переносы по оригиналу |
| OCR | Обнаруженные изображения на страницах 9 и 16 визуально соответствуют пиктограммам примечаний. Для основного текста и проверенных участков OCR не требуется |

У обоих руководств одна версия продукта, но разные шифры и назначение. При дальнейшем расширении корпуса следует различать документы по шифру с титула и сохранять исходное имя отдельным полем. Первым пилотным документом остаётся инструкция для Windows. Второе руководство проверено как дополнительный кандидат без включения PDF в Git.
