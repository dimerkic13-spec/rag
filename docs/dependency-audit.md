# Зависимости пилота Dify 1.9.2

Исследована ревизия ec871819e46de82f2f9ee33a71a61d96a58bdb37. Объект аудита — обязательные сервисы и программные контракты **выбранного профиля** PR #7. Дистрибутив содержит также альтернативные БД, Certbot и множество необязательных провайдеров. Для лицензирования транзитивных пакетов каждого образа нужен отдельный SBOM.

| Компонент | Исходное решение | Кандидат | Совместимость и изменения | Лицензия/статус | Источник |
| --- | --- | --- | --- | --- | --- |
| API, HTTP и миграции | Flask, SQLAlchemy 2, psycopg2, Alembic, PostgreSQL | Postgres Pro | Нужны две БД, uuid-ossp и проверка миграций на чистой и существующей схеме. Смена SQL-протокола требует изменения слоя хранения | Dify Modified Apache, драйверы имеют собственные лицензии; СУБД коммерческая. Анализ кода | [API](https://github.com/langgenius/dify/tree/1.9.2/api/migrations) |
| Векторы | Выбор VECTOR_STORE; в пилоте qdrant-client 1.9.0 | Platform V / YDB | Для Platform V проверить Search, Filter и payload; YDB потребует нового VectorBase и регистрации в factory | Поставка СберТех / Apache 2.0. Только автономный опыт YDB | [Фабрика](https://github.com/langgenius/dify/tree/1.9.2/api/core/rag/datasource/vdb) |
| Кэш и блокировки | redis-py 6.1, Redis | Radix | RESP, TTL, lock, sorted sets и атомарность. Сервер без Redis API требует переписать обращения, включая прямые вызовы | Коммерческий плагин; не проверено | [ext_redis](https://github.com/langgenius/dify/blob/1.9.2/api/extensions/ext_redis.py) |
| Очередь, worker, worker_beat | Celery 5.5 и Kombu, Redis transport | Radix или Synapse Messaging | Эмуляция Redis требует проверки команд транспорта. Другой брокер требует совместимый transport, настройку result backend и тест повторной доставки. Одной заменой брокера кэш не устраняется | Celery BSD, промышленный брокер по договору; не проверено | [ext_celery](https://github.com/langgenius/dify/blob/1.9.2/api/extensions/ext_celery.py) |
| Файлы, PDF, ключи и плагины | OpenDAL 0.46, локальный том | ФС сервера или согласованное S3-совместимое хранилище | Локальный том работает без передачи провайдеру. Отдельно проверить ACL, backup/restore | Apache 2.0 для OpenDAL, условия хранилища отдельно. Том проверен в RAG-004 | [ext_storage](https://github.com/langgenius/dify/tree/1.9.2/api/extensions/storage) |
| Генерация и embeddings | Два интерфейса model provider | GigaChat или согласованные сервисы Яндекса | Отдельно проверить chat и text embeddings; при отсутствии интерфейса реализуется плагин. Изменения ядра обычно не нужны | Условия API. Реальный вызов открыт | [Plugin SDK](https://github.com/langgenius/dify-plugin-sdks) |
| Plugin Daemon | langgenius/dify-plugin-daemon 0.3.3-local | Одобренный runtime с тем же протоколом не найден | Удаление механизма вызова провайдера потребует изменения кода или совместимой реализации протокола и хранения плагинов | Проверять LICENSE образа отдельно. Статический аудит | [Daemon](https://github.com/langgenius/dify-plugin-daemon) |
| Sandbox | dify-sandbox 0.2.12, исполнение code nodes | Отключение code nodes для конкретного flow либо совместимый sandbox | Для собственного несовместимого API требуется изменить клиент Dify. В профиле PR #7 сервис присутствует | Условия конкретного образа; не протестирован на замену | [Sandbox](https://github.com/langgenius/dify-sandbox) |
| SSRF proxy | Squid и egress-правила | Прокси организации | Нужны эквивалентные сетевые ограничения, DNS и HTTP proxy API. Отключение изоляции не допускается | Условия Squid и базового образа. Конфигурация изучена | [Compose](https://github.com/langgenius/dify/blob/1.9.2/docker/docker-compose.yaml) |
| Web и ingress | dify-web (Next.js), nginx, приватный маршрут к PDF | Одобренный HTTP reverse proxy | Проверить маршрутизацию консоли, API, streaming и авторизацию PDF. Замена всей UI потребует нового клиента | Dify с ограничениями на брендинг; nginx BSD. /install проверен ранее | [Compose и маршруты](https://github.com/langgenius/dify/tree/1.9.2/docker/nginx) |

Общие зависимости — Linux, OCI runtime, сеть, DNS/TLS, хранилище и секреты установки. Для продления версии нужно повторить аудит pyproject/lock и образов, проверку миграций и тесты.
