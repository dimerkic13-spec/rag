# Контрольные сценарии пилота

Эти сценарии подготовлены по результатам RAG-002. Исполнение отложено до появления развёрнутого бота. Формальный набор и пороги предстоит сверить с утверждённым ТЗ.

| Сценарий | Вопрос | Что проверять |
| --- | --- | --- |
| Ответ по тексту | Что нужно сделать после завершения установки дистрибутива КриптоПро CSP? | Ответ указывает на необходимость перезагрузки и ссылается на инструкцию для Windows, физическая страница 7 |
| Ответ по таблице | Поддерживает ли Chrome двусторонний TLS с клиентским ГОСТ-сертификатом при использовании свойства shadow? | Ответ соответствует таблице № 2 и ссылается на инструкцию для Windows, физическая страница 88 |
| Данных нет | Какова стоимость продления лицензии в 2030 году? | Бот явно сообщает о недостатке сведений в пилотной документации и не придумывает цену или источник |

Для каждого запуска сохраните версию конфигурации, вопрос, ответ, ссылки и результат сверки с оригиналом. Указанные сценарии проверяют ответы по тексту, работу с таблицей и отказ. Качество поиска по всему корпусу проверяется отдельно после расширения.
