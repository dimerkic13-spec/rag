# Журнал решений

| Решение | Статус |
| --- | --- |
| Пилот на одном продукте и одном PDF | Утверждено |
| GitHub для контроля версий вместо SourceCraft | Утверждено |
| Windows 11 как ОС разработки | Утверждено |
| Docker Desktop и WSL 2 для разработки | Установлены и проверены по данным проекта |
| Российское или Open Source ПО | Утверждённое ограничение |
| Python 3.13 | Предварительно выбран. Совместимость зависимостей проверяется в RAG-004 |
| Dify, GigaChat и GigaChat Embeddings | Предварительные кандидаты. Интеграции предстоит проверить |
| Qdrant или Platform V Vector DB | Выбор открыт до проверки совместимости и поисковых возможностей |
| Автоматизированное тестирование | Обязательно |

Действующее уточнение для продолжения проекта — использовать только российские алгоритмы и базы данных. Platform V Vector DB рассматривается как кандидат. Соответствие алгоритмов, системную СУБД и итоговую конфигурацию предстоит подтвердить в RAG-004.
