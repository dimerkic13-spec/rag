# Разметка и оценка приёмочного набора

В [книге Excel](../tests/datasets/rag_test_dataset.xlsx) 150 уникальных строк и восемь категорий с квотами §4.8 ТЗ. Три строки содержат черновики пилотных вопросов. Остальные заполняет эксперт. Для КриптоПро CSP пилот ограничен инструкцией Windows. Руководство по виртуальным средам предназначено для расширения. Названия, версии и согласованные документы продуктов 2 и 3 ещё нужны.

Перед испытанием эксперт сверяет каждый ответ и обязательные факты с утверждённой версией PDF, записывает шифр, версию и физические страницы, отмечает статус проверки. Для междокументного поиска перечисляет все пары документ/страница, для отказа подтверждает отсутствие ответа в заданном корпусе. Зафиксировать версию набора, корпуса, системного промпта, поиска и моделей. Исключить из формального запуска черновики и остановить приёмку, если утверждённых строк менее 150 или нарушены квоты.

Каждый вопрос отправляется в отдельном диалоге. Хранить локально пять первых результатов поиска в исходном порядке, идентификаторы сегментов, ответ, цитаты, задержку и ошибки. До запуска разметить релевантные сегменты для каждой обязательной страницы. На вопросах с ответом усреднять Recall@5 (доля найденных эталонных сегментов) и Precision@5 (число разных релевантных сегментов в первой пятёрке, делённое на 5). Пустая выдача даёт ноль. Для вопросов без ответа отдельно считать долю явных отказов без неподтверждённых сведений и ссылок.

Предлагаемая рубрика для согласования: Correctness — доля вопросов с ответом, где эксперт подтвердил все обязательные факты без противоречий. Faithfulness — доля фактических утверждений, подтверждённых извлечённым контекстом. Citation Accuracy — доля корректных ссылок по документу, версии, странице и смыслу; пропуск обязательной ссылки учитывается как ошибка. Для пустого знаменателя показывать «нет данных». Зафиксировать числитель, знаменатель, пропуски, причины ошибок и показатели по продуктам. Эксперт перепроверяет критические сценарии, расхождения и стратифицированную выборку остальных результатов.

Ориентиры §4.10: Recall@5 ≥ 90%, Precision@5 ≥ 75%, Correctness ≥ 85%, Faithfulness, Citation Accuracy и Abstention Accuracy ≥ 95%. Критических ошибок в API и ответах по установке, настройке, безопасности и криптографическим параметрам должно быть ноль. Шаблон, методика и три пилотных сценария ожидают утверждения для формальной приёмки.
