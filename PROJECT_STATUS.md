# Статус проекта

- Текущий этап — **1**.
- Текущий шаг — **1.3**.
- Пилот — один продукт и один PDF. Целевой масштаб — три продукта и около 30 PDF.

## Рабочее окружение

Windows 11 — согласованная ОС разработки. Docker Desktop и WSL 2 установлены и проверены по данным проекта. Python 3.13 — предварительная целевая версия. Проверка совместимости зависимостей запланирована в RAG-004. Контроль версий ведётся в GitHub.

## Выполнено

- RAG-001 — подготовлены структура каталогов, служебные документы, шаблон окружения и правила исключений Git. Сохранены существующие навыки Codex и учебная проверка реестра.
